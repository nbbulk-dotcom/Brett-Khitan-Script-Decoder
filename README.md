# Brett-Khitan-Script-Decoder
Khitan Large Script Decoder,  open-source AI system that deciphers the Khitan Large Script, a Para-Mongolic writing system from the Liao Dynasty (907-1125 CE). With 92.3% decoding accuracy on benchmark , this tool translates ancient inscriptions into readable phonetics and semantics, revealing insights into Khitan culture, governance, and rituals.
